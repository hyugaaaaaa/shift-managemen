# 不具合調査報告書：お知らせメール送信機能

## 1. 概要
お知らせ機能におけるメール送信が、登録済みのメールアドレスに対して正常に行われない不具合が発生していました。
本報告書では、特定された原因と、それに対する改善案（実施済みの修正内容）について記述します。

## 2. 発生事象
- 管理画面からお知らせを作成し「メール通知」を行っても、対象者にメールが届かない。
- 画面上では「XX名へメール通知しました」と表示される場合があるが、実際には送信されていない、または「メール送信対象がいませんでした」と誤った表示が出る。

## 3. 原因特定 (Root Cause Analysis)

調査の結果、以下の4つの複合的要因が特定されました。

### 3.1. データベース構成の不備 (Missing Table)
非同期送信用のキューを管理するテーブル `mail_queue` がデータベース上に存在していませんでした。
- **影響**: メール送信リクエストを一時保存しようとした時点でSQLエラーが発生し、処理が中断（または失敗として無視）されていました。
- **背景**: システムが同期送信から非同期送信（キュー方式）へ移行した際に、テーブル作成漏れがあった可能性があります。

### 3.2. バックグラウンド処理の未実行 (Process Trigger Failure)
メールをキューに保存した後、実際に送信処理を行うスクリプト `process_mail.php` が自動的に実行されていませんでした。
- **影響**: キューにデータが入ったとしても、手動でコマンドを実行しない限りメールが送信されない状態でした。

### 3.3. 環境設定の読み込み不全 (Environment Variable Loading Failure)
コマンドライン（CLI）環境で実行される送信プログラムが、設定ファイル `.env` を正しく読み込めていませんでした。
- **影響**: SMTPサーバーの設定（ホスト名、ユーザー名、パスワード、送信元アドレス）が空の状態で送信を試みるため、認証エラーや宛先不明で送信失敗していました。
- **技術的詳細**: Windows環境等のCLIにおいて、使用しているライブラリ `phpdotenv` がエンコーディング等の問題で `.env` のパースに失敗していました。

### 3.4. 実行コマンドのパス問題 (Path Resolution Issue)
プログラム内からPHPコマンドを呼び出す際に、相対パスまたはパスが通っていない `php` コマンドを指定していました。
- **影響**: Windows環境やXAMPP環境において `php` コマンドが見つからず、バックグラウンド処理が起動しませんでした。

## 4. 改善案・対応内容 (Countermeasures)

上記原因に対し、以下の対策を実施しました。

### 4.1. データベースの修正
- **対応**: `mail_queue` テーブルを新規作成しました。
- **効果**: 送信リクエストが正しくデータベースに蓄積されるようになりました。

### 4.2. 自動送信トリガーの実装
- **対応**: お知らせ作成完了時に、バックグラウンドで即座に送信プログラム (`process_mail.php`) を起動する処理を追加しました。
- **詳細**: Windows (XAMPP) 環境に対応するため、`start /B` コマンドと `php.exe` の絶対パスを使用するように修正しました。

### 4.3. 設定読み込みロジックの堅牢化
- **対応**: `config.php` にて、環境変数の読み込みに失敗した場合のフォールバック処理（手動パース処理）を追加しました。
- **効果**: ライブラリが `.env` の読み込みに失敗しても、独自ロジックで確実に設定値を読み込み、SMTP接続が成功するようにしました。

### 4.4. 冗長コードの整理
- **対応**: `process_mail.php` 内の重複した読み込み処理を削除し、`config.php` に一本化しました。
- **効果**: エラーの原因となる競合を排除し、保守性を向上させました。

## 5. 今後の運用・再発防止策
- **環境差異の考慮**: Webアクセスの環境とCLI（コマンドライン）環境では、環境変数の扱いやパスの通り方が異なることを考慮し、実装時には両方で動作検証を行うこととします。
- **ログの監視**: 今後メール送信エラーが発生した際に即座に検知できるよう、`mail_queue` テーブルの `status` カラムや `error_message` を定期的に確認することを推奨します。
