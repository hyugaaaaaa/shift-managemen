## 2. 問題点と改善提案 (Issues & Recommendations)

### 2.1 🔴 **Critical: メディアクエリの不足**

**問題:**
```css
/* style.cssで確認できたメディアクエリ */
@media (max-width: 768px) {
    .filter-btn { width: 4rem; }  /* 1箇所のみ */
}
@media print { ... }
```

**現状:** ブレークポイントが **768px の1箇所のみ** で、タブレット (768px-1024px) やスマートフォン横向き (480px-768px) への最適化が不十分。

**推奨:**
```css
/* 推奨ブレークポイント */
@media (max-width: 480px)  { /* スマホ縦 */ }
@media (max-width: 768px)  { /* タブレット縦 */ }
@media (max-width: 1024px) { /* タブレット横 */ }
@media (max-width: 1200px) { /* 小型ノートPC */ }
```

### 2.2 🟡 **Major: テーブルのレスポンシブ対応不足**

**問題:**
```css
.table {
    width: 100%;
    /* オーバーフロー対策なし */
}
```

**影響:** 
- 従業員一覧、月間集計などの横長テーブルがモバイルで横スクロール不可能
- 小画面でレイアウト崩れの可能性

**推奨:**
```css
@media (max-width: 768px) {
    .table-responsive-mobile {
        display: block;
        overflow-x: auto;
        -webkit-overflow-scrolling: touch;
    }
    
    /* または、カード型レイアウトへの変換 */
    .table-mobile-card thead { display: none; }
    .table-mobile-card tr {
        display: block;
        margin-bottom: 1rem;
        border: 1px solid #ddd;
    }
}
```

### 2.3 🟡 **Major: フォントサイズの固定値**

**問題:**
```css
.page-title { font-size: 1.75rem; }  /* 固定値 */
.payslip-title { font-size: 1.5rem; }
```

**推奨:** `clamp()` 関数による流動的なタイポグラフィ
```css
.page-title {
    font-size: clamp(1.25rem, 4vw, 1.75rem);
}
```

### 2.4 🟡 **Major: ナビゲーションバーのモバイル最適化**

**確認不足:** `template.php` のナビゲーション構造を確認できていませんが、一般的な課題:
- ハンバーガーメニューの実装状況
- メニュー項目の縦配置への変換
- タップ領域の確保

**推奨確認項目:**
```html
<!-- Bootstrap標準のCollapseを使用しているか -->
<button class="navbar-toggler" data-bs-toggle="collapse">
```

### 2.5 🟢 **Minor: カレンダーセルの固定高さ**

**問題:**
```css
.calendar-cell {
    /* 高さ指定なし → コンテンツ量で変動 */
}
```

**推奨:**
```css
@media (min-width: 768px) {
    .calendar-cell {
        height: 120px;
        overflow-y: auto;
    }
}
```

### 2.6 🟢 **Minor: ダークモード未対応**

**現状:** ライトモードのみ

**推奨 (オプション):**
```css
@media (prefers-color-scheme: dark) {
    :root {
        --bg-color: #1a1a1a;
        --surface-color: #2d2d2d;
        --text-color: #e0e0e0;
    }
}
```
