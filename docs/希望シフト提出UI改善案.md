# 希望シフト提出UI改善案

## 1. 背景・目的
ユーザーより、「希望シフト提出画面をカレンダー形式で、日付を選択して提出できるようにしたい」という要望がありました。
現行のフォーム形式（日付手入力）から、直感的で視認性の高いカレンダーUIへの刷新を提案します。

## 2. 改善案の概要

### コンセプト
**「カレンダーファースト」**な入力体験。
ユーザーはまずカレンダー上でシフト状況（提出済みかどうか）を確認し、任意の日付をクリックして新規登録や変更を行います。

### 画面イメージ
1. **メインエリア**: 大きなカレンダーを表示（当月・翌月切り替え可）。
2. **日付セル**:
   - 何も提出していない日は空白（クリック可能）。
   - 提出済みの日は「10:00-15:00 (承認待ち)」のようなバッジを表示。
3. **操作フロー**:
   1. カレンダーの「空いている日」をクリック。
   2. モーダルウィンドウ（ポップアップ）が開き、シフトパターン選択フォームが表示される。
   3. 入力して「提出」を押すと、カレンダー上に即座に反映される。

## 3. 技術的アプローチ

### ライブラリ選定: FullCalendar (v6)
信頼性とカスタマイズ性が高い標準的なJavaScriptライブラリ「FullCalendar」の採用を推奨します。
- **メリット**:
  - ドラッグ＆ドロップ対応（PC版）
  - スマホ対応（レスポンシブ）が容易
  - 既存のBootstrapテーマとの親和性が高い
- **導入方法**: CDN経由で読み込むため、サーバーへのファイル追加は最小限で済みます。

### 実装ステップ
1. **ビュー変更 (`submit_shift_view.php`)**:
   - 既存のフォームを隠し（またはモーダル内に移動）、メイン表示領域に `<div id='calendar'></div>` を配置。
   - 既存のシフトデータ（JSON形式）をビューに埋め込み、カレンダー初期表示時にイベントとしてレンダリング。
2. **JS実装**:
   - 日付クリックイベント (`dateClick`): モーダルの起動、クリックした日付をフォームに自動入力。
   - イベントクリックイベント (`eventClick`): 提出済みシフトの詳細表示または削除/編集。
3. **CSS調整**:
   - アプリケーション全体のテーマカラー（青基調）に合わせたカライジング。

## 4. 期待される効果
- **操作性向上**: 日付を手入力する手間がなくなり、直感的にシフトを組める。
- **視認性向上**: 自分の提出状況（どの日に出しているか）が一目でわかる。
- **ミス防止**: 重複提出や定休日の選択ミスをカレンダー上で視覚的にブロック可能。
