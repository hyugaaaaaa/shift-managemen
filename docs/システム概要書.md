# システム概要書

## 1. システム名称
アルバイトシフト管理・給与計算システム

## 2. システムの目的
本システムは、飲食店や小売店などの店舗運営において、アルバイト従業員のシフト管理業務および給与計算業務を効率化・自動化することを目的とします。
従来、紙やエクセルで行われていた複雑なシフト調整や、深夜割増を含む給与計算をシステム化することで、管理者の負担を軽減し、計算ミスを防ぎます。また、給与明細の電子交付により、ペーパーレス化を推進します。

## 3. 利用者と役割
| 利用者 | 役割 | 主な利用シーン |
| :--- | :--- | :--- |
| **オーナー (管理者)** | 店舗の責任者 | 従業員管理、シフト確定、給与計算確認、システム設定 |
| **パートタイム (従業員)** | アルバイトスタッフ | シフト希望提出、確定シフト確認（他従業員の出勤状況含む）、給与明細閲覧 |

## 4. システム全体像
本システムはWebアプリケーションとして提供され、PCおよびスマートフォンからブラウザを通じて利用します。

### 主な業務フロー
1.  **企業アカウント登録**: オーナーが企業アカウントを作成（招待コード発行）。
2.  **従業員登録**:
    *   **オーナー**: 従業員情報を手動登録（任意）。
    *   **従業員**: 招待コードを使用して自ら登録申請。
3.  **シフト希望提出**: 従業員がスマホ等から希望シフトを提出。
4.  **シフト作成・確定**: オーナーが希望を確認し、シフトを作成・確定。
5.  **勤務・集計**: （※本システムでは打刻機能は含まず、シフト予定時間を勤務時間として扱う運用を想定、または実績修正運用）
6.  **給与計算**: 締め日に基づき、深夜割増・交通費を含めた給与を自動計算。
7.  **明細交付**: 従業員がWeb上で給与明細を確認・印刷。

## 5. 特徴的な機能
*   **高度な給与計算**: 深夜時間帯（22:00〜05:00）の自動割増計算（25%UP）に対応。
*   **電子明細**: 法的要件（同意取得）を満たした上での給与明細電子交付機能。
*   **スキル管理**: 従業員のスキル（資格や業務可能範囲）を登録・管理し、最適な人員配置を支援。
*   **お知らせ・掲示板**: オーナーから従業員への一斉連絡機能。ダッシュボードに表示されます。不要になったお知らせは一括削除も可能です。

*   **定休日管理**: 毎週の定休日（曜日指定）と、月ごとの臨時定休日を設定可能。設定された日はシフト提出が制限されます。
*   **モバイル最適化**: オーナー向けに、スマートフォンからでも「定休日設定」「お知らせ管理」などの管理機能へ素早くアクセスできる「管理メニュー」を搭載。
*   **柔軟なシステム設定**: シフト提出締め切り日、給与締め日、給与支払日をオーナーが自由に設定可能。
*   **シフトパターン管理**: よく使うシフト時間（例: 早番 9:00-14:00）をテンプレートとして登録し、シフト作成時の入力を効率化。
*   **データ出力**: 給与明細やシフト表をCSV形式で出力し、サーバー（C:\shift_management）に保存可能。
*   **マルチテナント対応**: 1つのシステムで複数の企業を管理。企業ごとにデータ（ユーザー、シフト、設定）は完全に分離されます。
*   **企業内ユーザーID管理 (NEW)**: システム内部のIDとは別に、企業ごとに独立した連番の従業員番号（社員番号）を自動付番・管理します。
*   **招待コードシステム**: 企業ごとに発行される招待コードを用いることで、従業員がスムーズに所属企業へ登録できます。
*   **論理削除**: 誤操作によるデータ消失を防ぐため、ユーザー削除は論理削除（無効化）として実装。
*   **セキュリティ強化**:
    *   全フォームへのCSRFトークン導入による不正リクエスト防止。
    *   論理削除されたユーザーへのアクセスブロック機能。
    *   アカウントロック、セッションタイムアウト、パスワード変更機能。
    *   他企業のデータへのアクセスを厳格に制限するデータ分離制御。
*   **モダンなUI**:
    *   インディゴブルーを基調とした洗練されたデザイン。
    *   **レスポンシブデザイン完全対応**:
        *   PC、タブレット、スマートフォンなど、あらゆるデバイスで最適化された表示を提供。
        *   **2カラムレイアウト（PC版）**: ダッシュボードではカレンダーと詳細パネルを並列表示。希望シフト一覧では、一覧性を重視したテーブル（リスト）形式を採用し、効率的な管理を実現。
        *   **カード型レイアウト（モバイル版）**: スマートフォンでは、テーブル（シフト一覧、従業員一覧、時間集計）をカード形式に自動変換し、横スクロール不要の高い視認性と操作性を実現。ボタン配置もタッチ操作に最適化。
    *   カレンダーのマス目を均等配置し、視認性と操作性を向上（選択時のレイアウトズレ防止実装済み）。
    *   フェードインアニメーションによる滑らかな画面遷移。
*   **操作性の向上**:
    *   重要な操作（承認、削除など）における誤操作防止のため、Bootstrap Modalによる確認ダイアログを採用し、安全で直感的な操作を実現。
    *   **希望シフト管理の刷新**: 視認性の高いステータスアイコンとカードデザインにより、大量のシフト希望も効率的に処理可能。
*   **パフォーマンス向上**:
    *   メール送信処理を非同期化（キューイング）し、送信実行時の画面待機時間を解消。ストレスのない操作感を実現。
    *   **シフト提出の快適化**: PRGパターン採用による提出後のスムーズな画面リフレッシュと二重送信防止。

## 6. 技術的構成・アーキテクチャ
保守性、拡張性、安全性を高めるため、以下の技術的アプローチを採用しています。

### 6.1 採用技術スタック
本システムは、保守性とポータビリティを重視し、特定のサーバーサイドフレームワークに依存しないネイティブなPHPで構築されています。

| カテゴリ | 技術・ツール | 備考 |
| :--- | :--- | :--- |
| **言語 (サーバーサイド)** | PHP 7.4 以上 | フレームワーク不使用 (Native PHP) |
| **言語 (フロントエンド)** | HTML5, CSS3, JavaScript (ES6+) | |
| **データベース** | MariaDB 10.4 以上 (MySQL 互換) | XAMPP標準構成 |
| **Webサーバー** | Apache HTTP Server | |
| **フロントエンドFW** | Bootstrap 5.3 | レスポンシブデザイン、UIコンポーネント |
| **アイコンライブラリ** | Bootstrap Icons 1.10 | |
| **フォント** | Google Fonts | Inter (英数), Noto Sans JP (日本語) |
| **ライブラリ (Backend)** | vlucas/phpdotenv | 環境変数管理 (.env) |
| **ライブラリ (Backend)** | PHPMailer | メール送信 (SMTP対応) |

### 6.2 ロジックと表示の分離 (MVC構成)
プログラムの「処理ロジック（Controller）」と「画面表示（View）」を明確に分離しています。
*   **Controller**: データの取得、計算、保存処理を担当（例: `dashboard.php`）。
*   **View**: HTMLの生成と表示を担当（例: `views/dashboard_view.php`）。
これにより、デザインの変更がロジックに影響を与えず、安全かつ効率的に開発・保守が可能です。

### 6.2 共通ロジックの集約
給与計算やシステム設定の取得など、システム全体で利用される重要なロジックは `functions.php` に集約しています。
*   **一元管理**: 計算式やルールの変更が一箇所で完結し、修正漏れや計算ミスを防ぎます。

### 6.3 セキュリティ対策
*   **CSRF対策**: ログイン、登録、更新などの重要な処理において、CSRFトークンによる検証を導入し、不正なリクエストを防止しています。
*   **SQLインジェクション対策**: データベース操作にはPDOのプリペアドステートメントを使用し、安全性を確保しています。

### 6.4 非同期処理（バッチ）
*   **メール送信キュー**: メール送信は即時実行せず、一旦データベース（`mail_queue`）に保存し、バックグラウンドのバッチ処理（`process_mail.php`）で順次送信します。これにより、ユーザーの操作画面での待ち時間を最小限に抑えています。

## 7. ファイル構成

### 7.1 共通・基盤
*   `index.php`: ログイン画面（Controller）。初期登録機能も含む。
*   `register.php`: 初期アカウント登録画面（Controller）。
*   `dashboard.php`: ダッシュボード（Controller）。ログイン後のトップページで、シフトカレンダーを表示。
*   `config.php`: データベース接続設定および共通設定。
*   `functions.php`: 共通関数群（給与計算、設定取得、CSRF対策など）。
*   `template.php`: ヘッダー・フッターなどの共通HTMLパーツ。
*   `logout.php`: ログアウト処理。
*   `register_company.php`: 企業アカウント登録（Controller）。
*   `register_staff.php`: スタッフ（アルバイト）登録（Controller）。
*   `help.php`: ヘルプ画面（Controller）。
*   `change_password.php`: パスワード変更画面（Controller）。
*   `change_password.php`: パスワード変更画面（Controller）。
*   `process_mail.php`: 【バッチ】メール送信キュー処理用スクリプト。
*   `css/style.css`: サイト全体のデザイン定義。

### 7.2 オーナー機能 (`owner/`)
*   `users.php`: 従業員一覧画面（Controller）。
*   `user_edit.php`: 従業員登録・編集画面（Controller）。
*   `monthly_hours.php`: 月間労働時間・給与集計画面（Controller）。
*   `manage_requests.php`: シフト希望一覧・確定画面（カード型UI採用）。
*   `holidays.php`: 定休日設定画面（Controller）。曜日定休と臨時定休の設定。
*   `system_settings.php`: システム設定画面（Controller）。
*   `shift_templates.php`: シフトパターン設定画面（Controller）。
*   `announcements.php`: お知らせ管理画面（Controller）。
*   `export_data.php`: データ出力画面（Controller）。
*   `regenerate_code.php`: 招待コード再発行処理（Controller）。

### 7.3 アルバイト機能 (`parttime/`)
*   `submit_shift.php`: シフト希望提出画面（Controller）。
*   `view_schedule.php`: 確定シフト確認画面（Controller）。
*   `payslip_list.php`: 給与明細一覧・同意画面（Controller）。
*   `payslip_view.php`: 給与明細詳細・印刷画面（Controller）。

### 7.4 表示テンプレート (`views/`)

*   `reset_password_view.php`: パスワードリセット実行画面用。
*   `dashboard_view.php`: ダッシュボード用。

*   `privacy_policy.php`: プライバシーポリシー画面。
*   `help_view.php`: ヘルプ画面用。
*   `change_password_view.php`: パスワード変更画面用。
*   `owner/`: オーナー機能用テンプレート（`users_view.php`, `user_edit_view.php`, `monthly_hours_view.php`, `system_settings_view.php`, `shift_templates_view.php`, `export_data_view.php`）。
