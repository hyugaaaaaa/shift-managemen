# システムリリース手順書

このドキュメントでは、開発した「シフト管理システム」を本番サーバー（レンタルサーバー等）に公開し、稼働させるまでの手順を説明します。
PHPのプログラムは「コンパイル（変換）」が不要なため、**ファイルのアップロード**と**設定**が主な作業になります。

---

## 1. 事前準備

### 1-1. サーバー環境の確認
以下の環境が利用可能であることを確認してください。
*   **PHP**: バージョン 7.4 以上 (8.0以上推奨)
*   **データベース**: MySQL 5.7以上 または MariaDB 10.x以上
*   **Webサーバー**: Apache / Nginx 等
*   **SSL (HTTPS)**: セキュリティのため必須 (無料のLet's Encrypt等で可)

### 1-2. 必要なファイル
以下のファイル・フォルダ一式を使用します。開発環境(`c:\xampp\htdocs\shift_management`)にあるものを準備してください。

*   **アップロードが必要**:
    *   `src/` (プログラム本体)
    *   `views/` (画面表示ファイル)
    *   `public/` または `css/`, `js/` (画像、CSS、JavaScript)
    *   `vendor/` (ライブラリ一式。**重要**)
    *   `db/` (セッションハンドラなど一部使用するファイルがある場合)
    *   `.env.example` (設定ファイルのひな形)
    *   `index.php`, `config.php`, `functions.php`, `template.php` 等のルートディレクトリにある `.php` ファイル群
    *   `register.php`, `login.php` ... 等の各機能のPHPファイル

*   **除外しても良い(アップロード不要)**:
    *   `.git/` (Git管理フォルダ)
    *   `.gitignore`
    *   `tests/` (テストコード)
    *   `docs/` (ドキュメント)
    *   `README.md`
    *   `.env` (※ローカルの設定が含まれるため、アップロード後に**サーバー用の内容で別途作成**します)

---

## 2. データベースの移行

### 2-1. ローカルデータの書き出し (エクスポート)
1.  ローカルの **phpMyAdmin** (http://localhost/phpmyadmin) にアクセスします。
2.  `shift_management` データベースを選択します。
3.  「**エクスポート**」タブをクリックします。
4.  「実行」ボタンを押し、SQLファイル (`shift_management.sql`) をダウンロードします。

### 2-2. サーバーでのデータベース作成
1.  本番サーバーのコントロールパネル等で、新しいデータベースを作成します。
    *   **DB名**: (例: `username_shift`)
    *   **DBユーザー名**: (例: `username_dbUser`)
    *   **パスワード**: (強力なパスワードを設定し、メモしてください)
2.  本番サーバーの **phpMyAdmin** にログインします。
3.  作成したデータベースを選択し、「**インポート**」タブをクリックします。
4.  先ほどダウンロードした `shift_management.sql` を選択し、「実行」して取り込みます。

---

## 3. ファイルのアップロード

専用のFTPソフト（FileZilla, WinSCPなど）を使ってファイルをサーバーに転送します。

1.  FTPソフトでサーバーに接続します。
2.  公開ディレクトリ（`public_html` や `www` など）を開きます。
    *   ※もしサブディレクトリ（例: `/shift`）で運用する場合は、そのフォルダを作成してその中に入れます。
3.  **1-2** で確認したファイル・フォルダ一式をアップロードします。
    *   ※ファイル数が多い(`vendor`フォルダ等)ため、時間がかかる場合があります。

---

## 4. 本番環境の設定

サーバー上でシステムが正しく動くように設定を行います。

### 4-1. 設定ファイルの作成
1.  アップロードした `.env.example` ファイルの名前を **`.env`** に変更します。
    *   (ファイル名変更機能を使用してください。Windows上ではなくサーバー上で行うのがポイントです)
2.  `.env` ファイルを編集モードで開き、**2-2** で設定したサーバーのデータベース情報に書き換えます。

```ini
# Database Settings
DB_HOST=localhost       <-- 多くの場合は localhost ですが、サーバー会社指定のホスト名(mysql1.example.com等)の場合もあります
DB_NAME=username_shift  <-- 作成したDB名
DB_USER=username_dbUser <-- 作成したDBユーザー名
DB_PASSWORD=xxxxxxxx    <-- 設定したパスワード

# Other Settings
# ドメイン直下(例: example.com/)で動かす場合は空欄または /
# サブフォルダ(例: example.com/shift/)なら /shift
BASE_PATH=/shift        

# Mail Settings (任意)
# シフト通知メールを送る場合、SMTP情報を設定します
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
...
```

### 4-2. パーミッション(権限)の確認
*   ログファイル `app.log` が生成される場所などに書き込み権限が必要な場合があります。
*   エラーが出る場合は、ディレクトリの権限を `755` または `777` 等に調整してください（サーバーの仕様に従ってください）。

---

## 5. 動作確認

1.  ブラウザでサイトのURLにアクセスします（例: `https://example.com/shift/`）。
2.  **ログイン**できるか確認します。
    *   ※DBを丸ごとコピーしていれば、ローカルと同じユーザーID/パスワードでログインできます。
3.  基本機能（シフト提出、登録など）が動くかテストします。

### うまく動かない場合
*   **「Database Error」**: `.env` のDB設定(ホスト名、ユーザー、パスワード)が間違っていないか確認してください。
*   **「500 Internal Server Error」**: `.htaccess` の記述や、PHPのバージョンが古い可能性があります。サーバーのエラーログを確認してください。
*   **「404 Not Found」**: `BASE_PATH` の設定やファイルの配置場所を確認してください。

---

## セキュリティに関する注意
*   **`.env` ファイルは機密情報を含みます。** ブラウザから `https://example.com/.env` にアクセスできてしまわないよう、Webサーバーの設定(`.htaccess`)でアクセス制限をかけることを強く推奨します。XAMPP環境ではすでに設定済みの場合が多いですが、本番環境でも確認してください。
